# Hypurr 桌宠｜第二档配方：吃 Token / 原地小憩沉眠 / 轻快摇摆舞（品红背景版）

> 三条都属于插件的**随机动作池**（`animations.categories`），出好之后我会把权重打开——
> 猫在空闲时会自己随机播这三条。每条 prompt 已把前缀合并好，**整段复制一次即可**。

## 0. 清单（文件名＝插件槽位名，务必一致）

### 全局参数

| 项        | 值                                                   |
| -------- | --------------------------------------------------- |
| 首帧       | `video/ref-magenta-stand.png`（品红底标准站立图；**不要用绿幕那张**） |
| 模式       | 图生视频（有首尾帧功能就首尾都用同一张）                                |
| 时长       | **5 秒**（与已跑通的批次一致）                                  |
| 比例 / 分辨率 | 16:9 / 720p（或 1080p；别 4K）                           |
| 镜头       | 固定机位，不推拉摇移、不变光                                      |
| 生成条数     | 每条出 2~3 条挑最稳的                                       |

### 两条针对本批的硬约束

1. **道具/特效禁止用粉红、品红、紫红、玫红**（会和背景撞色被抠掉）——用青、蓝、绿、黄、白、深灰。
2. **首末帧都必须是标准站立**（这三条都是循环型小动作）。尤其 `原地小憩沉眠`：
   它是"打盹"不是"一直趴着睡"——素材链按**首末帧的站立高度**算缩放，
   末帧若保持趴姿会被算成偏小的比例，切到它时宠物会突然变小。

## 2. 自检清单

1. 首帧是不是干净的纯品红背景 + 标准站立 + 无任何道具/特效？
2. **末帧是不是回到同一个标准站立**（三条都是）？
3. 有没有**整体位移**（横移/后退）？→ 会让归一化对不齐
4. 耳尖/胡须/**尾巴**/道具/Zzz 气泡有没有碰到或超出画幅？
5. 背景是不是均匀的 `#FF00FF`、四角没有水印或渐变？
6. 角色有没有变形/换脸/变色？外套还是橄榄绿？
7. 道具/特效有没有误用品红、粉红、紫红？
