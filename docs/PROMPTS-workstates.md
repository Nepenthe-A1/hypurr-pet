## 0. 怎么用（3 步）

1. **首帧上传**：`video/ref-magenta-stand.png`（品红底标准站立图；**别再用绿幕那张**）
2. **整段复制**：从 §2 复制对应动作的那一个代码块（前缀已含在内）
3. **自检后另存**：按 §3 过一遍，另存为 **表格里给的文件名**（这个文件名就是插件的槽位名，别改）

### 全局参数

| 项 | 值 |
|---|---|
| 模式 | 图生视频（首帧＝`ref-magenta-stand.png`；有首尾帧功能就首尾都用它） |
| 时长 | **5 秒**（与首批一致，已跑通；想用 10 秒就把每条的第 2、3 段按比例拉长） |
| 比例 | **16:9** |
| 分辨率 | **720p 或 1080p**（别开 4K） |
| 镜头 | 固定机位，不推拉摇移、不变光 |
| 生成条数 | 每条出 **2~3 条**挑一条最稳的 |

### 本批清单（文件名 = 插件的槽位名，务必一致）

【画幅安全红线】全库安全缓冲统一为画幅任意一边的 10%。动作全程任何一帧，角色任何身体部位

角色来腾空间；角色与物件必须同框。
【"无→有→无"道具闭环】所有含道具/特效/交互对象的视频，入场第一帧必须是与参考图完全一致的
标准站立、画面干净——无任何道具、无任何特效；道具一律由角色以魔法手势从无到有、由虚到实地

【侧身互动 ≠ 构图横移】需要侧身/转身面向物件时，一律指角色原地轴心转动上身、头部或脚尖原地

【角色】见附带的参考图，全程保持完全一致的白猫外形、配色与服装，不得换脸、变形、变色。

6. 角色有没有**变形 / 换脸 / 变色**？外套还是不是橄榄绿？
