# Hypurr 桌宠｜素材清单与生成配方

> 目标：给 `dsh-pet`（DSH 桌宠插件，MIT，★2964）做一个 **Hypurr pet pack**。
> 它的素材链要求：**每个动作一段 10 秒品红背景视频** → 抠像 → 归一化 → 转成透明 webm。
> 本文件就是"你要生成的东西 + 每个东西的完整提示词 + 打勾清单"。

---

## 0. 怎么用这份文件（30 秒读完）

**每个动作三步走：**

1. **上传参考图** → 用 §2 的品红站立图做**首帧**（Seedance 有首尾帧功能就首尾都用它）
2. **粘贴两段** → 先贴 §3 的【通用前缀】，再贴 §4 里该动作的配方，合成一条 prompt
3. **自检后另存** → 按 §5 的 6 条过一遍，另存为 `<文件名>.mp4`

**全局参数（每个动作都一样）**

| 项 | 值 |
|---|---|
| 模式 | 图生视频（首帧＝参考图） |
| 时长 | **10 秒** |
| 比例 | **16:9** |
| 分辨率 | **720p 或 1080p**（别开 4K，最终播放变体只有 640×360，纯浪费） |
| 镜头 | 固定机位，不推拉摇移、不变光 |
| 生成条数 | 同一动作出 **2~3 条**挑一条最稳的 |

**两条硬规则（省一半工作量、避免返工）**

- **只做一个朝向**：插件把所有动画做 CSS 镜像，左右朝向不用各做一套。
- **不做侧视走路**：插件只有一套朝向，四足猫做侧视走路会与正面动作撕裂。移动统一用正面「原地小步弹跳」，屏幕漫游由程序平移。

## 0.5 ⚠️ 实测反馈（2026-10-20，先读这段）

### 已经就绪，不用再做

- **参考图已做好（已换品红底）**：`video/ref-magenta-stand.png`（2048×1152）+ `video/ref-magenta-stand-720p.png`（1280×720）
  —— 头顶 20%、脚底 85%、高度 65%、水平居中、纯 `#FF00FF`，左上水印和脚下接地阴影都已清掉。
  **直接拿它当首帧，不要再让即梦出参考图**（它出的那张角色占画幅 89.8%、还带"AI 生成"水印）。
  ⚠️ **首帧背景会被模型继承**：首帧是绿幕，出来的视频就还是绿幕 → 所以背景色一改，参考图必须跟着换。
  （这张是"整幅等比缩放 + 平移 + 换填充色"做出来的，只动了背景，角色像素级不变。）
- **第一条 `待机呼吸` 已验收并抠像完成**：`video/step02/待机呼吸.webm`（VP9 alpha / 1280×720 / 24fps / 5.04s / 1.5MB）。
  **这条不用重出**——素材链的 normalize 会按"站立高度→900px"重新统一尺寸。

### 三条实测教训（影响后面所有动作）

1. **大动作必须留足边距**：即梦会把角色画得过大（实测首条：头顶 6.7%、脚底 95.6%、高 88.9%）。
   待机这种小幅度动作无所谓（normalize 会修），但**跳跃 / 伸懒腰 / 拖拽悬空 / 敲键盘**这类动作一旦出画就被裁掉、无法恢复。
   → 用新的 `ref-magenta-stand.png` 当首帧能大幅缓解；出图后自检"耳尖/尾巴/爪子有没有贴边"。
2. **图片别存 JPEG**：JPEG 色度压缩会在轮廓外留"半色"噪点，抠像后形成杂边。能选 PNG 就选 PNG。
   （视频没这个问题，mp4 照旧。）
3. **时长**：单段循环动作（`待机呼吸` / `说话-碎碎念` / `原地打瞌睡`）**5 秒完全可以**；
   需要多阶段节奏的（`工作状态-敲代码` / `整理归档` / `雀跃庆祝`）请出 **10 秒**。

### 背景色为什么从绿幕改成品红（2026-10-20 决定）

**根因：这只猫穿的是橄榄绿外套，用绿幕抠就是绿对绿。** 量出来的角色自身颜色分布：

| 角色自身的有色像素 | 占比 | 代表色 | 色相 |
|---|---|---|---|
| 橄榄绿外套 | **约 30%** | `#3B674F` `#2D5247` | 145–170°（高光能漂到 140°） |
| 蓝灰虎斑 / 阴影 | 10% | `#6489A0` | 200–210° |
| 深藏青描边 | — | `#282F47` | ≈227° |
| 红爱心 / 粉耳肉垫 | 15% | `#DC3849` `#E3A0BF` | 330–360° |

对照各候选背景色到"角色最近本色"的角距离（抠像窗口 ±18°）：

| 背景色 | 最近角色本色 | 角距离 | 判定 |
|---|---|---|---|
| **绿幕 `#00FF00`** | 外套高光（黄绿） | **20–25°** | 危险 —— 之前所有坑（吃外套 / 闪烁 / 绿边）都源于此 |
| 青蓝 `#00FFFF` | 外套暗部（深青） | 2.5° | ❌ |
| 蓝幕 `#0000FF` | **深藏青描边**（线稿） | 12.5° | ❌ |
| **品红 `#FF00FF`** | 粉耳 / 肉垫 | **30°** | ✅ 采用 |
| 橙 `#FF8000` | 红爱心（仅特效） | 27.5° | 🟡 备选 |
| 紫 `#8000FF` | 深藏青描边 | 42.5° | ✅ 但模型还原度差、紫溢色明显 |

**换品红后规则大幅简化**：抠像只需一段"背景色相 ±15°"判定（脚本预设 `--preset magenta`），
**连去绿（despill）都关掉了** —— 因为没有任何角色本色落在窗口附近，也就不会出现
"分不清是污染还是外套"这类问题（衣服闪烁那个 bug 的根就在此）。
已完成的 3 条绿幕素材**不用重做**（抠完都是透明背景，源背景色不影响成品）。

> 历史记录：`dsh-pet` 自带的 `scripts/chroma_step02.py` 色相窗口写死 `[70,170]`，
> Hypurr 的外套（≈144°）会整片被抠成透明（实测复现）；我们改用自写的 `tools/key_green.py`
> （从四周采样真实背景色相 + 连通域过滤 + 边界带去绿闸门）绕过了它。
> 那套绿幕时代的细节仍留在脚本里（`--preset green` 可回到当时的参数）。

### 本项目新增的三个工具

| 工具 | 作用 |
|---|---|
| `tools/check_clip.py` | 每条素材过闸：构图/漂移/安全区/水印/首末帧一致性/真实帧率 |
| `tools/key_green.py` | 背景抠像 → 透明 VP9-alpha WebM（默认 `--preset magenta`；`--preset green` 回到绿幕参数） |
| `tools/make_reference.py` | 把任意角色图加工成合规首帧（抠像 + 水印遮罩 + 构图对齐 + `--bg` 指定背景色） |

> 附加情报：即梦 mp4 的**容器帧率元数据是假的**（标称 60fps，实际 24fps / 121 帧），
> 工具里已按"真实抽帧数 ÷ 时长"复算，不受影响。

## 3. 【通用前缀】每次必带（逐字用，别改数值）

> 这段是 dsh-pet 那份十万字配方库里最值钱的部分：它把"能抠像 + 能归一化对齐"的工程约束写死了。只抽掉了角色相关描述，其余原样保留。

```
【绝对空间与边界约束强制命令】
视频比例 16:9，背景必须为纯粹的品红色（Chroma Key Magenta，严格统一为 #FF00FF），
无任何阴影、杂物、渐变或边框，背景本身即为单一纯色块。
人物位置与大小强制固定：角色完完全全处于画面正中心偏下位置。头顶始终处于画面垂直方向
约 20% 的位置，脚底始终处于画面垂直方向约 85% 的位置，最左和最右边缘始终处于画面水平
方向约 25% 和 75% 的位置。不同视频之间的角色大小、位置、比例必须完全一致，不允许任何偏差。
人物周围缓冲区（防裁切）：头顶距画幅顶边至少保留 15% 画幅高度的背景空间，脚底距画幅底边
至少保留 10%，身体左右两侧距画幅边缘至少保留 10% 画幅宽度。
【画幅安全红线】全库安全缓冲统一为画幅任意一边的 10%。动作全程任何一帧，角色任何身体部位
（耳尖、胡须、尾巴、爪子、外套下摆）以及所有道具与特效对象，在最高点/最外点都必须与画幅
对应边缘保持 ≥10% 的间距；绝对禁止任何部位或对象接触、触碰、超出或被裁剪。动作全程必须在
画幅内部完成。
【绝对居中锚点】角色双脚落点坐标恒定为屏幕正中央，全程不允许产生 X 轴或 Y 轴平移位移
（仅允许轴心旋转、原地跳跃、脚尖原地点地）。无论出现多大体积的道具，角色与道具的组合视觉
重心必须始终保持在画面水平正中；严禁为了容纳道具而把角色整体向左右移动或靠向画幅边缘。
【大物件构图规则】出现较大物件（高度＞画幅 30%）时：物件必须位于角色正前方/正上方/环绕
角色轴线，并与角色共用画面水平中心线；若放不下就宁可把物件 Q 版缩小以整体入画，绝不移动
角色来腾空间；角色与物件必须同框。
【"无→有→无"道具闭环】所有含道具/特效/交互对象的视频，入场第一帧必须是与参考图完全一致的
标准站立、画面干净——无任何道具、无任何特效；道具一律由角色以魔法手势从无到有、由虚到实地
渐进凝聚生成（先出现半透明虚影轮廓，约 0.5~1 秒后凝实），绝不直接出现在起始帧；并在动作结束前
从有到无、由实到虚地渐次消散（约 0.5~1 秒化为光点淡去），使画面回到无任何道具的标准站立。
任何一帧都不得凭空出现未经生成过程的道具，最终帧不得残留任何道具或特效。
【侧身互动 ≠ 构图横移】需要侧身/转身面向物件时，一律指角色原地轴心转动上身、头部或脚尖原地
点地转向，双脚与画面中心原点始终保持静止、不横移、不后移、不靠边；凡"退后、后退、后移、
走到一侧、挪到旁边、偏右/偏左站位"等会造成整体位移的描述一律视为违规。
【首末帧锁定】以附带的参考图为第一起始帧（此帧画面干净、无任何道具或特效），
并在视频最后一秒（第 10 秒结束时）彻底恢复到与第一帧完全一致、无道具残留的标准站立姿态。
【镜头】固定机位，全程不推拉摇移、不变焦、不改变光照与曝光，背景品红色值全程不得有任何色差。
【角色】见附带的参考图，全程保持完全一致的白猫外形、配色与服装，不得换脸、变形、变色。
```

## 4. 核心动作配方（14 个）

> **每条用法**：`§3 通用前缀` + 下面该条的代码块 = 完整 prompt。首帧一律用 `ref-magenta-stand.png`。

### 1. 待机呼吸 ⭐ 首批 · `待机呼吸.mp4`
```
动作概述：Q版白猫原地站立，身体呈现自然、有节奏的轻微上下起伏（呼吸感）。双眼平视前方，
每隔 3~5 秒完成一次轻快眨眼。耳朵尖与尾巴进行极小幅度的舒缓左右摆动。无位移、不切边。
按秒分割：0~3秒 身体极轻微上下起伏模拟呼吸，每隔约 2 秒眨眼一次，前爪自然垂放；
3~7秒 头部极小幅度左右缓慢转动，胡须轻颤；7~10秒 恢复正视前方，呼吸幅度渐缓，
回到与第一帧完全一致的标准站立。
```

### 2. 原地打瞌睡 · `原地打瞌睡.mp4`
```
动作概述：站稳后眼睛渐渐半闭、脑袋一点一点地往下沉，随即被自己惊醒、猛地站直，
耳朵抖动两下，恢复标准站立。
按秒分割：0~2秒 由标准站立开始，眼皮变重、缓慢半闭；2~5秒 脑袋以极小幅点左右晃动
（点头打盹），耳朵松软；5~7秒 突然惊醒：眼睛圆睁、身体一颤、耳朵竖直、尾巴炸起；
7~10秒 放松下来，回到标准站立。
```

### 3. 东张西望 · `东张西望.mp4`

## 5. 自检清单（每条生成后逐条过，不合格就重生成）

1. **首帧**是不是干净的品红背景 + 标准站立 + 无任何道具？
2. **末帧**是不是回到**同一个**标准站立？（`被拖拽悬空` 例外，见该条备注）
3. 身体有没有横向/纵向**位移**（原地跳除外）？→ 有位移会导致归一化对不齐
4. 耳尖/胡须/尾巴/道具有没有**碰到或超出**画幅？→ 会被裁切
5. 品红色是不是**均匀的 #FF00FF**、有没有阴影或渐变？
6. 角色有没有**变形 / 换脸 / 变色**？

> 经验：同一动作多出 2~3 条挑一条，比事后修补便宜得多。
